# FTC AutoScout Mobile — full-featured phone-first port

This project is a mobile-first Kivy interface built around the **AutoScout 4.1.0** calculation and data engine. It is designed to be developed and previewed on Windows, with iOS packaging delegated to a GitHub Actions macOS runner.

## Branding

The app retains the desktop brand palette and bundled logo:
- Primary maroon: `#5d081f`
- Light page background: `#eef1f6`
- White cards, dark slate text, and the original `AutoScout_Logo_56.png`

## Engine retained from AutoScout 4.1.0

`autoscout_core.py` is generated from the non-GUI engine of the supplied AutoScout 4.1.0 source. It preserves the existing calculation models and data workflows, including CAP, OPR, projected OPR, EPA, match predictions, calibrated chance-of-winning, alliance strength, standings, FTCScout API/cache, session serialization, analysis reports, and CSV/HTML/text exports. The original Tkinter UI is not imported by the mobile app.

## Mobile sections

Home, Setup, Teams (including manual data overrides), Matches and predictions, My Team, Standings, Alliances, Charts/data trends, Analysis, Live Scouting notes and stream link, FTC team research, Scout assignments/watchlists, and Settings/model basis.

Saved sessions and FTCScout cache use the app's private data directory. Scout roster and watchlist metadata are stored locally in `mobile_state.json`.

## Windows development (Python 3.11)

1. Extract this folder on Windows.
2. Run `windows_setup.bat`.
3. Run `RUN_WINDOWS_PREVIEW.bat`.

This launches the Kivy phone-style preview on Windows. It is a development preview, not a Windows rewrite of the old Tkinter app.

## Build the iOS Xcode project from Windows

1. Create a GitHub repository and upload the contents of this folder (including `.github/workflows/ios-project.yml`).
2. Open the repository's **Actions** tab.
3. Choose **Build AutoScout iOS project** and select **Run workflow**.
4. When the run finishes, download the `AutoScout-iOS-XcodeProject` artifact.
5. The artifact is an Xcode project generated by a hosted macOS runner. For installation on a physical iPhone, it still needs Apple code signing and a distribution path such as TestFlight or a development provisioning profile.

The workflow currently generates and uploads the Xcode project; it does not claim to create a signed IPA. Signing is intentionally not automated or embedded because it requires the developer's Apple credentials and provisioning profile.

## Important testing note

The calculation engine is reused directly from the AutoScout 4.1.0 desktop package. The Kivy screens are a mobile interface implementation and should be tested against your live FTC events and saved sessions before competition use. The Charts screen now renders grouped CAP / OPR / EPA horizontal bar charts and a color-coded match win-probability view. Match cards use compact alliance rows with wrapped, responsive text rather than fixed-height stacked controls.

### Color-coded scouting view
Match cards and match details distinguish Red and Blue alliances with matching tinted backgrounds and text. Completed matches emphasize the actual winning alliance. The configured team number is highlighted in team, match, standings, and alliance views; selecting another team in the Teams or Standings screen changes the highlight and saves that selection.
